Documentação oficial da **Plataforma de Gestão de Benefícios Eventuais**, sistema utilizado para gerenciar cadastro de cidadãos, solicitações, concessões, pagamentos, monitoramento, fornecedores e relatórios.

O conteúdo é orientado a usuário final. Detalhes de API, DTOs, permissões internas e implementação aparecem apenas quando ajudam suporte ou publicação.

## Convenções

| Elemento da interface | Como aparece no manual |
| :-- | :-- |
| Botão ou item de menu | **Aprovar**, **Salvar Rascunho** |
| Caminho de tela | `/solicitacoes/em-analise` |
| Status de entidade | *Em Análise*, *Aprovada* |
| Protocolo gerado | `PGBEN-2026-000123` |
