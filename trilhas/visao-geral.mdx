O PGBen organiza a operação de benefícios eventuais por papéis. A mesma tela pode aparecer para mais de um perfil, mas a responsabilidade muda conforme o trabalho de cada pessoa.

Use esta pagina como ponto de partida quando estiver treinando uma equipe, revisando um fluxo ou procurando o proximo capitulo.

## Como usar as trilhas

1. Comece pela trilha do seu papel principal.
2. Abra os capitulos indicados apenas quando precisar executar o fluxo.
3. Use o [changelog](/changelog/ultimas-entregas) para entender entregas recentes que podem mudar a rotina.
4. Use o [indice remissivo](/apendice/indice-remissivo) quando souber o termo, mas nao souber a pagina.

<Warning>
As telas exibidas no sistema dependem do acesso liberado para cada usuario. Se uma opcao citada no manual nao aparecer, confirme primeiro o perfil do usuario, a unidade vinculada e o contexto da entidade aberta.
</Warning>
